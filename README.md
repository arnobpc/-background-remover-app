# 📸 Gadget/Phone Background Remover App (Bangla)

এই প্রজেক্ট দিয়ে আপনি মোবাইল বা গ্যাজেট পণ্যের সাদা ব্যাকগ্রাউন্ড সরিয়ে HD PNG পেতে পারেন।

---

## 🔧 কিভাবে ব্যবহার করবেন

### ✅ ধাপ ১: GitHub এ আপলোড করুন

1. এই প্রজেক্ট unzip করুন
2. GitHub এ নতুন রিপো তৈরি করুন
3. সব ফাইল GitHub এ আপলোড করুন (app.py, requirements.txt, frontend/index.html)

### ✅ ধাপ ২: Hugging Face এ ডেপ্লয় করুন

1. যান [https://huggingface.co/spaces](https://huggingface.co/spaces)
2. `Create New Space` দিন
3. Space নাম দিন, SDK: `Gradio`
4. আপনার GitHub রিপো URL দিন
5. Create করুন এবং Deploy হয়ে যাবে

## 🌐 আপনার ফ্রন্টেন্ড ব্যবহার করতে
